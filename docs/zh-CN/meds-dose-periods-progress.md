### 开封逻辑（applyStockDelta）
初始 `1盒 + 5片 + 2片散装`，服用 8 片：
1. 散装 2 片扣完
2. 整板余量 5 片（不足一板）→ 全部转散装
3. 散装耗尽 → 自动开封新盒（1盒→0盒，30片）
4. 取 1 板（10 片）转散装
5. 扣 1 片 → 散装剩 9 片

### 药品计数 bug 修复（本次新增）
**Bug 根源**：`remainingPills` 被当作"整板余量"，但用户输入的是"总数"（含散装药）。
旧逻辑 `loose = (37 % 20) + 17 = 34` 重复计算散装药。

**修复**：
- `remainingPills` 语义改为"当前剩余总数"（含散装药 loosePills）
- `calcRemainingBreakdown`：整板部分 = 总数 - 散装药，再折算板数
- `applyStockDelta`：扣减时优先散装药，散装耗尽自动开封（整板→新盒）
- `percent`/`predictDepletion`：不再重复相加散装药
- 详细数量不显示总数量，剩余栏显示总数

**验证**（阿立哌唑 0盒 每盒2板 每板20片 总数37 散装17）：

### 库存模型重构（boardCount 新模型，本次新增）
**新模型**：`boxCount`（未开封盒数）+ `boardCount`（已开封整板数）+ `loosePills`（散装药）
- 总数 = 盒数×每盒板数×每板粒数 + 已开封板数×每板粒数 + 散装药
- 表单：填写盒数/板数/散装药后**自动计算总数**（只读显示）
- 开封逻辑：先消耗散装药 → 散装=0 打开一板（板数-1，散装=每板片数）→ 无板开封新盒（盒数-1，板数+每盒板数）
- 旧数据迁移：从 remainingPills 反推 boardCount

## 关键设计

### 库存模型
- `boxCount`：未开封盒数
- `boardPerBox`：每盒板数（规格）
- `pillsPerBoard`：每板粒数（规格）
- `remainingPills`：已开封整板余量（片）
- `loosePills`：散装药（不足一板，片）

### 开封逻辑（applyStockDelta）
1. 扣减优先散装药（loosePills）
2. 散装药耗尽 → 从 remainingPills 取出一整板转散装药
3. remainingPills 不足一板 → 全部转散装药
4. remainingPills 为 0 → 开封新盒（boxCount - 1，remainingPills = boardPerBox × pillsPerBoard）
